# ShimGen Lab - Third-Party Software

This lab bundles the following third-party software for educational simulation purposes:

* **shimgen.exe**
  * **Source**: https://github.com/enihsyou/shim_executable
  * **License**: MIT
  * **Note**: Compiled from source. Used as an open-source replacement for the Chocolatey shim generator.

* **rcedit.exe**
  * **Source**: https://github.com/electron/rcedit
  * **License**: MIT
  * **Note**: Official Electron utility used for modifying PE headers and icons.

* **putty.ico**
  * **Source**: https://www.putty.org/
  * **Note**: Icon extracted from the official PuTTY distribution. Used strictly for visual masquerading simulation.

* **payload.ps1 & lab_start.ps1**
  * **Source**: Developed internally for this lab.
